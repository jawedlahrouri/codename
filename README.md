## 📘 Description
**Codename** est une implémentation assistée par Intelligence Artificielle du célèbre jeu de société *Codenames*. Le projet explore les capacités de traitement automatique du langage naturel (NLP), de raisonnement sémantique et de modélisation adverse par Prompt Engineering structuré.
